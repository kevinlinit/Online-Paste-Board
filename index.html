Connect this computer

Your text is stored in a private (secret) GitHub Gist on your own account, so every computer you sign in on sees the same board.

  1. Create a GitHub token with only the gist scope (pick an expiration you're comfortable with).
  2. Paste it below. It is saved only in this browser.
  3. Repeat on your other computer (you can reuse the same token).

Open this page on another computer to see what you saved. Ctrl/⌘+S saves.
